# CodeAlpha Project 1 – Responsive Picture Gallery

## 📌 Project Overview

This project is a responsive picture gallery developed as part of the CodeAlpha Internship Program.

The gallery is designed to provide a clean and interactive way to view images on different screen sizes.

## ✨ Features

- Responsive image gallery
- Next and Previous navigation
- Lightbox image viewing
- Hover effects and smooth transitions
- Mobile-friendly design
- Clean and simple user interface
- Images adjust according to different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
